# Templates 目录

本目录保存可以被人员、Agent 和产品共同使用的结构模板。模板只定义需要收集、检查或输出的字段及说明，实际任务数据、审批记录和证据进入机构受控环境。

| 目录 | 内容 |
| --- | --- |
| [`tasks/`](tasks/README.md) | 任务输入、步骤、检查点和完成条件模板。 |
| [`evidence/`](evidence/README.md) | 与 Verification 中 EvidenceRequirement 对应的证据结构模板。 |
| [`deliverables/`](deliverables/README.md) | PRD、TRD、政策、评估、报告等候选交付物结构。 |

模板文件使用稳定 ID 和版本，记录适用 Topic、知识版本、必填字段、敏感数据级别、脱敏要求和人工确认点。模板不能复制法规结论，也不能包含真实机构或客户数据。
