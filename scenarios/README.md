# Scenarios 目录

本目录保存跨领域工程验收场景。场景围绕客户开户、电子货币与资金保护、支付执行、金融犯罪调查、数据保护和 ICT 中断等真实业务旅程组织，用来验证同一固定知识版本能否被人员、Agent 和产品一致使用。

```text
scenarios/<scenario-id>/
  README.md
  scenario.yaml
  expected.yaml
```

| 文件 | 用途 |
| --- | --- |
| `README.md` | 说明业务背景、范围、参与角色、敏感数据边界和人工决定点。 |
| `scenario.yaml` | 保存脱敏输入、目标任务、允许的知识版本和执行约束。 |
| `expected.yaml` | 保存必须出现的引用、控制、待确认项、失败条件和禁止结论。 |

场景不得包含客户数据、生产配置、有效凭据或未公开监管往来。固定预期用于工程验收，不表示真实机构已经合规。当前没有场景包；第一个场景在实际 EMI 产品范围确认后创建。
