# EMI Knowledge V1.0 Roadmap

- 状态：规划中
- 开始日期：2026-09-08
- 当前固定发布：`v0.3.0`
- 目标发布：`v1.0.0`
- 当前步骤：总体范围和目录职责已确认，专题清单与实施顺序待讨论

## 目标

V1.0 形成面向 Malta 母国 EMI、支持后续 EU/EEA 展业的核心监管与工程知识基线。详细法规范围、横向维度、排除项和六个验收场景以[根 README 的 V1.0 范围](../../README.md#v10-范围)为准。

## 工作流

| 工作流 | 当前状态 | V1.0 目标 |
| --- | --- | --- |
| EMI & Payments | 尚未开始 | 建立牌照、电子货币和支付服务核心知识链。 |
| DORA | 已发布三个 Topic | 补齐 ICT 风险管理、韧性测试和 ICT 第三方风险等范围。 |
| GDPR | 尚未开始 | 建立面向 EMI 客户、交易、员工和合作方数据的核心知识链。 |
| AML/CFT | 尚未开始 | 建立客户尽调、持续监控、交易监控、报告和资金转移信息知识链。 |
| Restrictive Measures | 尚未开始 | 建立动态名单治理、筛查、命中处置、冻结、禁止交易和报告知识链。 |

## 规划规则

1. 每次只确认并建设一个能够独立检查的 Topic。
2. 每个 Topic 先完成来源复核和覆盖矩阵，再建立受控知识对象。
3. 共用对象只维护一次，通过 Topic 引用，不按法规复制。
4. 每个中间发布继续固定 Topic、对象修订、来源输入、内容摘要和限制。
5. `v1.0.0` 发布前完成六个跨领域场景和至少一个脱敏真实 EMI 产品范围的工程验收。

具体里程碑、版本编号和顺序将在首个 V1.0 Topic 确认后加入本目录，不提前创建空计划文件。
