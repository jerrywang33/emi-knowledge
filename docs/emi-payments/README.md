# EMI & Payments 文档

本目录用于 EMI 牌照、电子货币和支付服务领域的人员可读文档。V1.0 范围包括牌照与治理、资本、客户资金保护、电子货币发行与赎回、代理与分销、外包与跨境展业，以及支付执行、SCA、欺诈、退款、投诉和报告。

计划中的领域全景文件为 `emi-payments-landscape.md`，专题说明进入 [`topics/`](topics/README.md)。来源基线和逐专题来源复核统一保存在 [`docs/sources/`](../sources/)。

当前尚未形成已批准 Topic。首个全景或专题文件将在 EMD2、PSD2、Malta Financial Institutions Act/FIR 及 PSD3/PSR 迁移状态完成来源复核后创建。
