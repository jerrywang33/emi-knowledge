## 专题范围

本专题覆盖电子货币机构在 DORA 完整 ICT 风险管理框架和简化框架下的 ICT 变更管理要求。内容包括变更政策、受控生命周期、职责与审批分离、安全影响分析、测试、回退、紧急变更和实施后检查。

机构自身的变更分类、人员安排、风险阈值和证据保存期限需要在具体使用时确认。事件管理、业务连续性、韧性测试和第三方风险只保留与变更直接相关的依赖。

## 当前知识链

专题清单以 15 项 Requirement 为入口，沿知识关系解析 3 个 Source、20 个 Provision、3 个 Decision、8 个 Control 和 8 个 Verification。`v0.1.0` 共固定 57 个对象、147 条关系和 16 类证据要求。

完整内容、限制和独立使用结果分别见 [`v0.1.0` 发布记录](../../releases/v0.1.0.md)与[独立使用验收](../../acceptance/v0.1.0.md)。专题清单在 `v0.2` 引入，用于后续按专题检查和组合发布；它不会改变已经固定的 `v0.1.0` 发布目录或 Git tag。
