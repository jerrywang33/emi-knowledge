# EMI Knowledge v0.1.0 独立使用验收

- 验收日期：2026-09-02
- 验收版本：`v0.1.0`
- 发布级别：`engineering_baseline`
- 内容摘要：`572112de29790efa365b5fd25b764ada419fde99c34ee59e38be881dfb88f3e7`
- 验收范围：人员阅读、Agent 上下文和产品查询接口

## 验收环境

验收直接使用 [`releases/v0.1.0`](../../releases/v0.1.0/README.md) 中的固定文件，不接入 EMI Harness、Agent Runtime、数据库、向量检索或网络服务。人员路径使用生成的 Markdown，Agent 路径使用 `agent-context.json`，产品路径使用 `knowledge.json`。

本次 Agent 验收检查版本锁定、稳定标识、来源层级、关系解析、待确认项和回答结构。真实模型的自然语言质量、工具调用和长上下文行为需要在后续项目接入中继续验证。

## 自动化检查

执行命令：

```bash
npm run check
npm run example:query -- req-full-change-fallback
```

最终检查包含 12 个自动化测试：

- 3 个独立使用测试，覆盖产品查询、Agent 版本锁定与回答结构、三类发布文件一致性。
- 2 个发布测试，覆盖重复生成和仓库发布文件漂移。
- 7 个模型与知识图测试，覆盖正常知识链和主要失败场景。

查询示例先使用公开 Schema 校验机器文件，再锁定版本并解析关系。未知版本、未知 ID、错误目标类型和 Schema 失败都会终止读取。

## 验收修正

本轮处理了三个工程问题：

1. 增加固定版本读取器，使用方必须声明期望版本，避免默认读取其他发布。
2. 增加 Source、Requirement、Control、Verification 和 EvidenceRequirement 的直接查询接口，产品无需自行猜测关系字段。
3. 删除查询结果中重复的证据数组，Verification 信息和 EvidenceRequirement 各保留一份。

本轮未发现需要修改来源映射、监管要求或工程控制内容的问题。

## 剩余限制

- 尚未由外部法律顾问、具体机构合规人员或主管机关确认法律适用性。
- 尚未使用真实 EMI 的组织角色、系统配置、变更记录和运行证据进行业务验收。
- Agent 验收覆盖确定性上下文和回答契约，未覆盖具体大模型的准确性、稳定性和提示词质量。
- 当前完整知识链只覆盖 DORA ICT 变更管理，其他 DORA 主题和其他法规领域仍需后续版本扩展。

## 结论

`v0.1.0` 通过独立工程使用验收，可以作为人员、Agent 和产品后续试用的固定 DORA ICT 变更管理工程基线。该结论不包含具体机构法律适用性、合规状态或生产就绪判断。
