# Restrictive Measures 文档

本目录用于欧盟和 Malta Restrictive Measures 的人员可读文档。V1.0 范围包括风险暴露评估、名单治理、客户和交易筛查、命中调查、资产冻结、禁止提供资金、报告、反规避和证据要求。

计划中的领域全景文件为 `restrictive-measures-landscape.md`，专题说明进入 [`topics/`](topics/README.md)。来源基线和逐专题来源复核统一保存在 [`docs/sources/`](../sources/)。

当前尚未形成已批准 Topic。动态名单只记录权威来源、获取时间、版本和使用规则，实时判断依赖受控外部数据，不依赖仓库静态副本。
