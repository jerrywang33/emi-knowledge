# EMI Knowledge v0.2.0

- 版本日期：2026-09-07
- 发布级别：`engineering_baseline`
- 内容范围：DORA ICT 变更管理；ICT 事件管理、分类与监管报告
- 内容摘要：`5c8c30cbba76bcfbece378b48427d8d02d97384b12799113b8c3051f7c0557bd`

## 发布结果

`v0.2.0` 固定了两个 DORA 专题及其共享对象：

| 专题 | 修订 | 独立闭包 |
| --- | ---: | ---: |
| `dora-ict-change-management` | 1 | 57 个对象 |
| `dora-ict-incident-management-reporting` | 7 | 204 个对象 |

组合发布包含 10 个 Source、115 个 Provision、81 个 Requirement、8 个 Decision、21 个 Control 和 21 个 Verification，共 256 个对象、679 条受控关系和 42 类 EvidenceRequirement。共享对象在发布中只保存一次。

事件专题的 66 项入口 Requirement 分别关联一个主 Control。13 项事件 Control 覆盖事件接入与记录、检测告警、响应恢复、分类、报告触发、报告阶段与时限、报告内容、安全提交、外包与汇总、沟通、复盘、趋势分析及年度成本损失；13 项 Verification 共定义 26 类证据要求。

## 待确认内容

Manifest 保留 125 个 `institution_defined` 实施项，主要包括机构角色、内部阈值和目标、系统与渠道、提交权限、模板来源、参考年度、证据来源系统和保存期限。

事件 Topic 另行保留 3 个来源问题：

1. Malta 非 ICT 重大支付运营或安全事件的当前流程、模板和提交入口。
2. MFSA 请求 DORA Article 11(10) 年度成本与损失估算的条件和传输方式。
3. MFSA Portal 用户指南的稳定日期、版本和替代关系。

## 发布边界

本版本完成来源映射、知识关系、通用工程控制、验证、证据模板、Topic 组合和固定发布的工程审查。审查范围未包含具体机构法律适用性、真实事件分类、实际监管报告、生产配置、运行证据或合规状态。

外部提交需要机构授权角色执行。Agent 可以提供受来源约束的分析和候选材料，不能批准事件分类、自愿通知或监管提交。本版本不构成法律意见、监管批准、合规认证或生产就绪结论。
